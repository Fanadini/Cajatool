Para qué sirve actualizar un monto por inflación

Con inflación, un mismo monto en pesos compra cada vez menos. Por eso, para comparar precios, sueldos o deudas de distintas épocas hay que expresarlos en pesos de un mismo momento. Esta calculadora lo hace con el Índice de Precios al Consumidor (IPC) del INDEC, el indicador oficial de inflación.

Algunos usos habituales:

  • Saber si tu sueldo le ganó o le perdió a la inflación en el último año.
  • Comparar el precio actual de un producto o servicio con el que pagabas antes.
  • Estimar cuánto debería valer hoy una deuda, una cuota o un presupuesto viejo.
  • Actualizar montos de un contrato cuando las partes acordaron usar el IPC.

Cómo se calcula

El IPC es un número índice: mide el costo de una canasta de bienes y servicios respecto de un período base (diciembre de 2016 = 100). Para actualizar un monto se usa el cociente entre el índice de los dos meses:

Monto actualizado = monto × IPC del mes de destino ÷ IPC del mes de origen

La inflación acumulada es ese cociente menos uno. Las variaciones mensuales no se suman: se multiplican. Tres meses de 2 % no dan un 6 %, sino un 6,12 %.

¿Tu sueldo le ganó a la inflación?

Es uno de los usos más frecuentes. Cargá tu sueldo bruto de hace un año como monto, elegí ese mes como origen y el último mes disponible como destino. El resultado es el sueldo que tendrías que cobrar hoy para mantener el mismo poder de compra. Si tu sueldo actual es mayor, tuviste una mejora real; si es menor, perdiste poder adquisitivo. La diferencia porcentual entre los dos es tu variación de salario real.

Lo mismo sirve para precios: si un servicio que pagabas $ 20.000 hace un año hoy cuesta $ 32.000, compará ese aumento con la inflación del período para saber si subió más o menos que el resto de los precios.

Limitaciones del cálculo

El IPC mide la inflación promedio de una canasta de consumo típica. Cada hogar consume distinto: si gastás más en alquiler, transporte o salud, tu inflación personal puede ser mayor o menor que la oficial. Además, el índice nacional promedia las regiones del país; el INDEC también publica datos por región (GBA, Pampeana, Noreste, Noroeste, Cuyo y Patagonia) y por categorías, como alimentos o servicios regulados.

Para deudas judiciales, créditos o contratos que fijan otro mecanismo de actualización —el CER, las UVA, el ICL o una tasa de interés—, hay que usar el índice que indique cada caso. Esta calculadora es una referencia útil para comparar valores en el tiempo.

Cómo usar la calculadora

Ingresá el monto, elegí el mes en que tenía ese valor y el mes al que querés llevarlo. El resultado muestra el monto equivalente, la inflación acumulada entre los dos meses y el promedio mensual del período.

Fuente de los datos

Los valores del IPC nacional del INDEC se obtienen de la API oficial de series de tiempo de datos.gob.ar y se actualizan automáticamente cada semana. La serie disponible va desde diciembre de 2016, cuando empezó el IPC nacional actual, hasta el último mes publicado.
